# DevtoolE2eInterceptor for iOS

Prebuilt binary distribution of the Dev Scenario iOS SDK (`DevtoolE2eInterceptor / DevtoolE2eInterceptorAuto`) for Swift Package Manager.

This repository contains only what Swift Package Manager needs to install the SDK: a `Package.swift` that points at
the XCFramework attached to each GitHub release. The SDK's source is not published.

## Install

Xcode → File → Add Package Dependencies… → `https://github.com/devscenario/httpinterceptor-ios`

The first binary release is published shortly; until then this repository has no installable version.
